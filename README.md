# Remix of Art

I wanna make a in-web iPad oriented whole advanced drawing thing, but with a simple UI inspired by procreate but mostly also inspired by iPadOS UI and liquid glass and stuff. Can you do that? I would like the simple layout to be a floating topbar for tools and access to all you need, and two left vertical bars on the side containing sliders for size and opacity of the brush.
